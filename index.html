MINECRAFT 1.20.1/ FORGE 47.3.0
01 — FONCTIONNALITÉS

Tout ce qu'il faut pour rejoindre le serveur, rien de plus.

JAVA

Java 17 installé pour vous

Détecte un Java 17 existant ou télécharge automatiquement le JRE Temurin, vérifié par empreinte SHA-256.

FORGE

Forge 1.20.1 prêt à jouer

Installe Forge 47.3.0 avec les bibliothèques et assets vanilla nécessaires, sans manipulation.

SYNC

Modpack toujours à jour

Mods et config synchronisés depuis le serveur par hash : seuls les fichiers modifiés sont retéléchargés, avec reprise en cas de coupure.

AUTH

Connexion Microsoft directe

Connexion via votre navigateur, sans le launcher officiel. La session est renouvelée en silence aux lancements suivants.

UPDATE

Mises à jour automatiques

Le launcher détecte les nouvelles versions et se met à jour en un clic.

SUPPORT

Diagnostic et réparation

Détecte les crashs courants (RAM, Java, mod corrompu), répare le modpack et génère un rapport à coller sur Discord.

02 — PRÉREQUIS

Ce qu'il vous faut

SYSTÈME Windows 10 ou 11, 64 bits
COMPTE Compte Microsoft possédant Minecraft Java Edition
JAVA Rien à installer : Java 17 est téléchargé automatiquement si absent
ESPACE DISQUE Quelques Go libres pour le jeu, Forge et le modpack
